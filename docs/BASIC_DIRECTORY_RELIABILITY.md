# 파트너사·심의위원 명단 처리

두 관리 화면은 공통 처리로 정확 건수 분할 조회, 행 검증, 화면 종료 응답 무시, 재조회를 적용한다. 조회 실패는 빈 목록과 구분하고 공유 명단 실패를 샘플로 대체하지 않는다.

등록은 반환된 실제 ID·이름·활성 상태를 확인한 뒤 입력을 지운다. 상태 변경은 조회 당시 변경 시각과 활성 상태를 조건으로 사용하며 실제 반환 행을 검증한다. 변경 결과 미확정 시 재조회 전에 추가 처리를 제한한다. 원시 DB 오류는 화면에 출력하지 않는다. 브라우저 테스트 모드 파트너사 저장은 저장소 쓰기 성공 후 화면에 반영한다. 심의위원의 로컬 등록은 계속 제공하지 않는다.

실제 처리 함수와 조회 effect를 모의 DB로 검사한다. 운영 DB 권한 정책·동시 요청·감사 이력 및 새 신청/심의 선택 화면의 조회 흐름은 별도 검증 사항이다. DB 구조와 권한 정책은 변경하지 않는다. 기본 스키마의 updated_at 갱신 트리거가 상태 변경 조건의 전제이다.
