# 1시간 미사용 보호 — 브라우저 1차

- 로그인된 AppShell 업무화면에서 55분 무입력 시 안내, 60분 경과 시 화면 제거 및 Supabase local signOut.
- 클릭/터치/키 입력/휠을 활동으로 처리하며 포인터 이동, 자동 데이터 갱신, 토큰 갱신은 활동으로 보지 않습니다.
- 여러 탭은 사용자·인증 세션별 localStorage 활동 시각을 공유합니다. 재로그인은 새 시작 시각을 기록합니다. 단순 새로고침은 연장하지 않습니다.
- 만료 후 첫 입력으로 세션을 되살리지 않습니다. 절전/비활성 탭은 복귀 시 경과시간을 확인합니다. 열린 화면의 타이머 확인 간격은 15초입니다.
- 저장된 고객 정보는 수정/삭제하지 않습니다. 미저장 입력은 로그아웃으로 잃을 수 있음을 경고합니다. 자동 저장으로 처리하지 않습니다.
- 로그아웃 오류가 발생해도 업무화면은 제거하고 다시 로그인하도록 안내합니다. 서버 세션 폐기 성공을 보장한다는 뜻은 아닙니다.
- 활동 시각 저장에는 토큰/고객 정보를 포함하지 않습니다. JWT session_id 해석은 키 구분용이며 권한 판단에 사용하지 않습니다.
- 브라우저 저장이 차단되면 열린 탭의 메모리 타이머만 동작합니다. 탭 간 공유·재시작 후 유지가 보장되지 않습니다.

## 한계 및 다음 작업

클라이언트 코드나 localStorage를 조작할 수 있으므로 이 기능은 서버 강제 만료나 MFA의 대체가 아닙니다. 직접 API/DB 요청, JS 비활성, 다른 기기의 기존 토큰까지 차단하려면 서버 세션 정책·DB/RLS·인증 공급자 설정이 필요합니다. 인증 서비스 토큰 자체의 유효기간 및 갱신 정책은 이번 작업에서 변경하지 않았습니다. 이 기능만으로 운영 보안 요구사항 완료로 간주하지 않습니다.

실제 로그인 상태에서 탭 공유, 55/60분 경계, 절전 복귀, 로그아웃 실패, 재로그인 검증은 배포 후 수행합니다. 자동검사는 시간 판단과 키 분리 12개만 확인합니다.
