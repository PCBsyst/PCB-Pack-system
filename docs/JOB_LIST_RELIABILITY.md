# Job 목록 상태 정합성

## 2026-10-04 개선

- Job 인증상태는 저장된 jobs.certification_state를 사용한다. 발행일이 있다고 유지로 판단하지 않으며 만료일만으로 상태를 변경하지 않는다.
- 상태가 없거나 알 수 없는 값이면 미확인으로 표시하고 별도 필터를 제공한다. 진행 업무기록이 없는 경우 서류검토 단계로 추정하지 않는다.
- 재조회 버튼은 연결 신청·Job·업무기록을 다시 읽는다. 조회 실패와 실제 빈 결과를 구분한다.
- 등록 Job과 기본 샘플 수를 구분한다. 발행번호·발행일·만료일은 현재 신청 업무 입력에서 읽으며 인증원장 자동 대조는 이번 작업의 범위가 아니다.
- 실제 화면·권한별 조회 검증은 별도다. 인증상태 변경 권한·데이터 변경은 없고 새 SQL도 필요 없다.
# 인증원장 대조 추가 (2026-10-04)

- 번호·발행일·만료일은 인증원장의 history_state=CURRENT 기록에서 표시한다. 이전 절의 업무 입력 표시 기준을 대체한다.
- 신청 입력값과 일치/불일치, 원장만 존재, 입력만 존재, 기록 없음, 조회 미확인, 현재 원장 복수를 구분하고 필터를 제공한다.
- 입력값은 펼쳐보기에서 확인할 수 있다. 원장·입력 어느 쪽도 자동 수정하지 않는다.
- 조회 실패나 복수 CURRENT 기록은 원장 값을 선택하지 않는다. 과거 이력을 현재로 임의 대체하지 않는다. 인증상태는 계속 jobs 저장값을 사용한다.
- 단일 조회 시점 대조이며 트랜잭션 잠금·전체 원장 무결성 보증은 아니다. 권한 범위에서 조회된 결과이며 실제 DB·브라우저 검증은 별도로 필요하다. 추가 SQL은 없다.
