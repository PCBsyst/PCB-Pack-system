# 업무 중심 메뉴·설정 레이아웃

좌측 메뉴는 업무현황 / 인증업무 / 인증 후 관리 / 기준정보 / 운영관리로 구분한다. 신청 접수·검토, Job 심의·발행, 기록 패키지를 업무순서로 배치하며 후보자와 연수기관은 기준정보로 분리한다. 메뉴명은 안내용이며 실제 단계 권한·상태·저장 경로를 변경하지 않는다.

설정은 사용자·권한 / 기준정보 / 업무규칙 / 문서양식 / 보안·이력으로 나눈다. 선택된 카테고리만 보이되 폼 컴포넌트는 유지해 탭 변경 시 미저장 입력이 사라지지 않는다. 각 설정의 기존 저장 버튼을 유지한다. 화면 이동·새로고침 시에는 저장하지 않은 값을 보장하지 않는다.

최고관리자는 설정·이관·개인정보 접근이력 메뉴를 보며, 서브 관리자는 직원 초대 메뉴만 본다. UI 숨김이 권한 검사 대신은 아니며 기존 서버·DB 검사도 유지한다.

검증: 로컬 가상데이터 환경의 데스크톱 1440px / 모바일 390px, 카테고리 전환, 영업일 입력 변경 후 다른 카테고리 왕복 시 유지, 모바일 메뉴 Escape 닫기 및 버튼 포커스 복원, 설정 페이지 가로 넘침 없음. 실서버 사용자별 저장·권한은 추가 확인이 필요하다.

디자인 참고: GOV.UK의 사용자 업무에 따른 탐색 구성 및 Carbon의 공통 헤더·페이지 탐색 분리 원칙. 외부 이미지·폰트·UI 라이브러리는 추가하지 않았다.
