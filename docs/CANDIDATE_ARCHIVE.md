# 후보자 보관 및 복원

- 활성 직원은 사유를 입력하여 보관·복원합니다. 삭제 기능은 이번 범위에 포함하지 않습니다.
- 후보자 목록의 기본값은 일반 후보자이며 보관/전체 필터로 조회합니다.
- 신청·Job·인증상태·문서·패키지는 변경하지 않습니다.
- 서버에서 직원 권한, 필수 사유, 기존 상태를 검사하고 행 잠금으로 중복 처리를 방지합니다.
- 기존 후보자 감사 트리거가 행의 변경 전후 값, 실행자, 시각, 사유를 기록합니다.
- SQL 202610030019_candidate_archive.sql 적용 전에도 기존 화면은 사용할 수 있으며 보관 작업은 비활성화됩니다.
- SQL은 사용자 작업을 후순위로 두기 위해 준비만 했습니다. 실제 DB 저장, 권한별 거부, 새로고침 후 유지 검증은 적용 후 필요합니다.
- 후보자 목록은 후보자 기본 테이블을 조회하여 신청/Job 연결이 없는 후보자도 포함합니다. 전체 조회 실패 시 연결 업무에서 확인된 후보자만 표시하고 조회 실패를 안내합니다.
