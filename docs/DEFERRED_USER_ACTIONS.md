## 적용 후 한 번에 검증할 항목

- 실무자: 사유 없이 보관/복원 거절, 사유 입력 후 저장 및 새로고침 유지.
- 보관 후보자: 일반 목록 제외, 보관 목록 조회, 연결 업무·인증상태 불변.
- 최고관리자: 업무이력 없는 오등록만 삭제, 이름 재입력·사유 필수.
- 실무자 및 서브 관리자: 삭제 RPC와 직접 DB 삭제 거절.
- 업무이력 있는 후보자: 최고관리자도 삭제 거절. 과거 신청/Job 감사기록도 검사.
- 변경 중 동시 요청: 상태 또는 수정 시각 불일치 거절.
- 후보자 기본정보: 두 탭에서 같은 후보자 조회 후 첫 저장 성공, 두 번째 저장은 충돌로 거절 및 내 입력 유지. 최신 정보 재조회 후 수정 가능, 보관/이관 변경 후에도 충돌 감지. 구형 저장 RPC 우회 거절.
- 고객 정보 직접 UPDATE 사유 없이 거절, 기존 정정/보관 RPC 정상 동작. 이력 테이블 직접 INSERT/UPDATE/DELETE/TRUNCATE 거절. 기존/신규 후보자 이관은 임시 삭제 없이 성공하고 모호한 동일인 매칭은 거절되는지 시험.
- 감사이력: 처리자·서버 시각·사유·변경 전후 값 유지. 실제 삭제는 복원 버튼으로 되돌릴 수 없음.
- 오등록 삭제는 후보자 기본 테이블에서 제거하는 기능입니다. 감사이력의 변경 전 정보는 보존하므로 개인정보 완전 파기 기능과 구분합니다.
- 기능 제어: 최고관리자만 사유 입력 후 변경, 일반 직원 직접 RPC/UPDATE 거절, OFF 상태에서 직접 문서 API 요청 거절, 기존 기록 유지. 문서 생성 OFF이면 ZIP도 생성 불가.

## 별도 운영 검증 대기

- 월간 업무보고: 분야/등급/유형별 고유 고객 수, 통합 인보이스 균등 배분, 발행월·입금월 분리, 월/연 접수 고객 현재 상태 분포 검증. 과거 월말 상태 복원은 미구현. 다크모드 주요 화면 가독성 확인. 신규 SQL 불필요.
- MFA 로그인 연결: 등록 완료 계정의 비밀번호 로그인 후 코드 화면 표시, 오입력 시 홈으로 이동하지 않음, 정상 코드 후 홈 이동, 취소 시 세션 종료 확인. 등록 계정 및 최고관리자의 페이지/서버 API 보호를 보완했다. 신규 SQL 불필요. 직접 DB 인증 수준 강제·미등록 직원 전체 적용은 후속 작업이다.
- 내 계정 보안: 인증 앱 QR 등록, 잘못된 코드 거절, 정상 코드 승인, 새로고침 후 상태 유지 확인. 최고관리자는 등록/인증 전 업무 진입이 제한된다. 신규 SQL 불필요. 관리자 복구·15일 신뢰 기기는 아직 미적용이며 실제 설정 키/코드는 공유하지 않습니다.
- 후보자 미저장 입력: 수정 중 일반 메뉴 이동·새로고침/닫기 경고, 저장 후 경고 해제, 실패/충돌 후 입력 유지, 보안 종료 방해 없음 확인. 자동저장 및 모든 SPA 뒤로가기 보호는 아님. 새 SQL 불필요.
- 설정 → 보안·이력 → 운영 전 점검에서 DB 조회 상태 확인. 조회 가능은 SQL 함수·저장·권한·실제 업무 전 과정 정상 작동 증명이 아니므로 아래 실행 검증을 별도로 수행합니다. 점검 화면 자체에는 신규 SQL 불필요.
- 패키지: 실제 DOCX ZIP 생성 후 문서 수·언어·내용 확인, 일부 양식 미등록 시 전체 완료되지 않는지 확인, OFF/오류 시 완료 선기록 없음, 공유 워크스페이스 저장 후 새로고침 유지. 과거 생성이력은 실파일 별도 확인.
- 서버 생성기록: 생성 후 기록 ID·직원·시각·포함 문서·ZIP SHA-256 확인, 일반 직원 직접 INSERT/UPDATE/DELETE 거절, 기록 저장 오류 시 다운로드 중단. SQL 022 미적용이라는 명확한 RPC 오류일 때만 적용 대기로 기존 다운로드 유지.
- 미사용 세션 보호: 브라우저 55분 경고·60분 로그아웃, 다중 탭·절전 복귀·재로그인 시험. 서버 강제 세션 만료/MFA 설정은 별도 후속 작업이며 현재 적용 완료로 간주하지 않습니다.
- 기존에 미뤄둔 직원 이메일 변경 후 로그인 시험.
- 실제 백업/복원 시험, MFA·세션 정책 등은 별도 공급자 설정과 운영 검증이 필요합니다. 자동 운영 중이라고 간주하지 않습니다.
- 배포 및 위 마이그레이션 적용 여부는 아직 확인하지 않았습니다.
