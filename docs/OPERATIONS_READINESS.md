# 운영 전 점검 화면

설정 → 보안·이력 → 운영 전 점검. 최고관리자만 실행 가능하며 새로운 SQL 적용은 필요하지 않습니다.

- 로그인/최고관리자 상태 확인 후 기존 테이블·필요 열에 limit(0) 조회 요청. 고객 행·이력 내용은 가져오지 않습니다.
- 누락 테이블/열과 연결/권한 오류를 구분합니다. 조회 성공은 저장 함수·트리거·RLS·전체 업무 흐름 검증이 아닙니다.
- SQL 020 삭제 함수는 실데이터를 삭제해 검사하지 않습니다. 별도 역할·삭제 시험 항목에 표시합니다.
- 로컬 가상데이터 모드에서는 DB 검사를 수행하지 않고 미검증으로 표시합니다.
- DB 조회 성공만으로 실제 개인정보 이관 승인·보안 충족·백업 정상 실행을 선언하지 않습니다.
- 자동백업/복원, MFA/서버 강제 만료, 공식 양식/PDF, 샘플 전 과정, 배포·이관은 별도 구축 및 실행 검증 필요로 표시합니다.
- 점검 결과는 해당 화면의 일시적 상태입니다. 공유 검수 결과의 DB 저장, 승인 워크플로, 배포 버전 검증은 이번 범위에 포함하지 않습니다.

자동검사: node scripts/test-operations-readiness.mjs — 오류 분류/집계/점검 목록 11개 검사. 실제 운영 DB 점검은 화면 접속 후 읽기 전용 요청으로 확인합니다.
