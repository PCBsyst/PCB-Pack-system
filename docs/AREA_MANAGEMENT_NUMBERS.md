# ISO / K뷰티 관리번호 분리

- 관리 No.는 ISO와 K뷰티 각각 연속 부여합니다. Job No.와 인증번호의 고유성 기준은 변경하지 않습니다.
- 이관 파일에서 같은 분야의 같은 관리번호는 차단합니다. 분야가 다르면 같은 번호를 허용합니다. 앞자리 0은 숫자로 정규화합니다.
- 발행분야 누락·알 수 없는 분야는 등록하지 않습니다. 관리번호 정책 조회 오류도 등록을 차단합니다.
- DB 변경 028 적용 전에는 기존 공통 번호 할당을 유지합니다. 서로 다른 분야의 동일 번호 이관은 028 적용 전 차단합니다.
- 028은 기존 번호를 바꾸지 않습니다. 과거 공통 예약 번호의 최대값을 두 분야에 보수적으로 승계하므로 일부 번호 간격은 남을 수 있습니다. 적용 후 구버전 공통 할당 요청은 거절됩니다.
- 운영 DB에는 아직 적용하지 않았습니다. 023이 선행되어야 하며, 알려진 이관 함수 구조가 다르면 전체 변경을 취소합니다.
- 자동검사 및 빌드는 별도 검증입니다. 실제 DB 동시 등록·RLS·이관 검증 완료를 의미하지 않습니다.
