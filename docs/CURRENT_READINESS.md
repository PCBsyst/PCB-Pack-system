4. 통계 정합성: 과거 월말 인증 상태 추이와 실제 수익 배분 기준 검증.
5. 이관: 전체 구글 시트 매핑·중복/불명확 기록 검토, 대조 및 병행 운영 후 전환.
6. 실무 검증: 직원이 신규·갱신·전환·인정/비인정 사례를 실제 세션에서 끝까지 검증.

## 이번 문서 입력 보호

인증 날짜는 입력된 값만 검사한다. 초안·전자본 발행일, 만료일, 원본 송부일이 실제 달력 날짜가 아니거나 만료일이 전자본 발행일보다 빠르면 화면 점검에 표시하고, 공통 문서 요청 검증에서 거절한다. 정식 세 문서·국문 검토 초안·ZIP 경로가 같은 검증을 사용한다. 미입력 날짜를 추정하거나 저장 날짜/인증상태를 바꾸지 않는다. 같은 날 만료하는 경우나 초안/원본 송부 순서에 새로운 업무 규칙을 임의로 부여하지 않는다. 운영 DB 제약·공휴일 검증을 추가한 것은 아니다.

패키지 사전 업무 점검을 다운로드 버튼보다 위에 배치했다. 인증번호의 공백 입력도 누락으로 표시하며 만료일을 점검 항목에 포함했다. 인증정보 누락 안내에서 같은 탭의 인증정보 입력 구역으로 이동할 수 있다. 입력 점검 통과는 서버 원본 대조·양식 준비·출력 검증 완료를 의미하지 않으며, 이 화면 안내 자체가 생성 차단 규칙을 추가하지는 않는다.

패키지 화면에서 선택된 Job의 시험 통보일·시험일·인증서 발행일과 문서전달확인서 기록일을 대조하고, 서로 다르면 해당 기록으로 이동하는 안내를 표시한다. 수령 여부가 체크되지 않았거나 해당없음/날짜 미입력인 항목은 대조하지 않는다. 서로 다른 사건의 날짜일 수 있으므로 오류로 단정하지 않고 자동 수정·다운로드 차단·저장값 변경도 하지 않는다. 이는 날짜 관계 규칙이나 실제 업무의 진위를 검증하는 기능이 아니다.

교육·시험 일정은 저장값 그대로 생성한다. 입력이 존재하면 선택 Job의 기관 구분·명칭·날짜 형식을 검사하며, 불가능한 날짜와 구성 오류를 생성 전에 거절한다. 빈 날짜를 사실로 채우거나 날짜 순서를 새로 계산하지 않는다. 이전 업무기록에 일정 항목 자체가 없는 경우는 호환하되, 저장된 일정이 있는데 요청에서 누락한 경우 저장값 대조 단계에서 차단한다.

정지·철회 보고서/통보문도 실제 내장 양식 두 개로 API를 실행해 출력 내용을 검사했다. Word의 분리된 텍스트 때문에 이름이 빠지고 통보문에 선택/날짜 안내가 남던 부분을 문단 단위 치환으로 수정했다. 안내 문구가 남으면 실패 응답을 반환한다. 서버 생성 파일 해시·크기·양식 버전/해시를 전달하고 클라이언트는 파일 검증 후 다운로드한다. 두 버튼은 생성 중 중복 클릭을 제한하고 오류를 표시한다. 이 검사는 인증/원본 DB/접근이력을 모의하며 인쇄 배치나 실제 운영 DB 권한 확인은 아니다.
