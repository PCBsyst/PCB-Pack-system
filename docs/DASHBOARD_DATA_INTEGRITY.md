# 대시보드 조회 무결성

Supabase 연결 모드에서는 초기 로컬 신청 데이터를 표시하지 않는다. 공유 DB 조회 실패 시 카드/업무 목록을 숨기고 오류와 재시도 버튼을 표시한다. 성공 시 한국 기준 조회 완료 시각을 표시한다. DB 워크스페이스가 없을 때 로컬 브라우저 업무 상태로 대체하지 않는다.

신청은 접수일 내림차순 및 ID 정렬로 500건씩 읽어 기본 조회 건수 제한에 따른 누락을 줄인다. 조회 중 재시도와 언마운트 응답은 폐기한다. 로컬 가상데이터 모드에서는 기존 가상 신청만 표시한다. 신규 SQL은 없다.

주의: 페이지별 조회는 한 시점의 DB 스냅샷을 보장하지 않는다. 실 DB 장애/권한/다중 직원 변경 검증은 별도 필요하다. 신규 상태 계산이나 백업 완료를 보장하는 변경이 아니다.
