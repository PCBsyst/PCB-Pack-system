# 미저장 후보자 기본정보 보호

- DB 후보자 기본정보 화면에서 조회한 값과 현재 입력을 비교하고 수정 사유 입력도 미저장으로 표시합니다.
- 저장 응답 확인 후 기준값을 갱신하고 DB의 마지막 수정 시각을 표시합니다. 조회 실패 시 기본정보 수정 저장을 허용하지 않습니다.
- 저장 중 입력을 막고, 저장 실패/충돌 시 내 입력을 유지합니다.
- 새로고침/탭 닫기/전체 문서 이동은 beforeunload 브라우저 기본 경고를 사용합니다. 같은 탭의 일반 링크로 다른 화면 이동 시 확인을 요청합니다. 새 탭/다운로드/수정키 클릭/같은 페이지 앵커는 제외합니다.
- 1시간 미사용·인증 로그아웃은 보안 종료 신호로 경고를 우회합니다. 미저장 입력으로 보안상 종료를 차단할 수 없습니다.
- 고객 개인정보 초안을 localStorage/sessionStorage에 저장하지 않습니다. 이 기능은 경고이지 자동저장/오프라인 복구가 아닙니다.

## 적용 범위와 한계

현재 DB 후보자 기본정보 및 수정 사유만 대상으로 합니다. 보관 사유·다른 화면 입력은 범위 밖입니다. 브라우저 뒤로가기의 SPA 이동, 프로그램에 의한 router 이동, 프로세스 종료·모바일 앱 종료는 전부 차단하지 못합니다. 브라우저 정책에 따라 경고가 표시되지 않을 수 있습니다. 미저장 데이터 보존을 보장하지 않습니다.

실제 브라우저의 이동 확인·닫기 경고·저장 후 경고 해제·보안 종료는 별도 실행 검증이 필요합니다. 자동검사는 링크 이동 판단 로직에 한정합니다.
