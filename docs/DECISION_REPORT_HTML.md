# 인증결정보고서 HTML 디자인 검토

신청 상세 → 패키지 → 인증결정보고서 HTML 디자인 검토에서 Job 및 선택 언어별로 생성한다. 현재 입력을 먼저 저장해야 하며, 운영 환경에서는 저장된 신청·Job·업무기록과 대조한 뒤 문서를 반환한다.

## 제공 기능

- 국문·영문 미리보기, 독립 HTML 다운로드, 브라우저 인쇄창을 통한 PDF 저장.
- 5개 평가 항목, 선택된 심의위원, 대표자 최종 승인, 인증정보를 별도 구획으로 표시.
- A4 인쇄용 머릿글, 페이지 번호, 장문 의견의 여러 페이지 출력.
- 미입력 항목은 미입력으로 표시하고 승인·서명·날짜를 추정하지 않는다.
- 영문 의견이 필요한 경우 기존 번역 누락 검사를 적용한다. 자동 번역은 하지 않는다.

## 기록과 접근 보호

기존 직원 권한·세션·문서 생성 정책과 개인정보 접근이력 검사를 적용한다. 접근이력을 남길 수 없으면 문서를 반환하지 않는다. 응답은 캐시하지 않으며, HTML은 외부 자원과 스크립트를 사용하지 않는다. 화면에서는 스크립트 실행이 허용되지 않는 별도 프레임으로 표시한다.

응답 바이트의 SHA-256과 크기를 수신 시 검증한다. 문서에는 생성 시각·양식 버전·기록 스냅샷 해시를 포함한다. 이는 전자서명이나 다운로드 후 파일 변경 방지 기능은 아니다. 입력 변경 시 이전 미리보기를 폐기한다.

이번 출력은 **디자인 검토본**이다. 기존 정식 DOCX, 인증 승인 상태, 패키지 완료 기록은 변경하지 않는다. PDF는 브라우저에서 저장하므로 실제 PC 저장 완료나 서버 보관을 보장하지 않는다. SQL 변경 및 추가 설치는 필요하지 않다.

## 검증 범위

렌더러·API·다운로드 검증·미리보기 처리 회귀검사를 추가했다. 인증과 DB 응답은 모의 검증이며 운영 DB 권한 검증과 구분한다. 가상 데이터의 국문·영문 각 2쪽 및 장문 국문 4쪽을 Chrome으로 PDF 생성하고 모든 페이지를 이미지로 확인했다. 외부 자원 요청은 0건이다.

다음 확대 대상은 신청서류 검토서와 문서전달확인서이다. 정식 패키지의 HTML/PDF 전환 및 서버 PDF 자동 보관은 별도 작업으로 진행한다.
