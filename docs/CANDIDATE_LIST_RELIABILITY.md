# 후보자 목록 정합성

## 2026-10-04 개선

- 고객 ID 기준의 기존 통합 표시를 유지한다. 동명이인을 이름으로 병합하지 않는다.
- 신청 수는 서로 다른 신청 ID 수, Job 수는 Job ID 기준 중복 제거 수로 집계한다. 로컬 Job ID 미지정 기록은 신청 ID와 Job 번호로 구분한다.
- 발행일만으로 유지 인증 보유를 판정하지 않고 저장된 jobs.certification_state를 사용한다. 유지 인증이 없고 상태 미확인 Job이 있으면 미확인으로 표시한다.
- 만료일만으로 인증상태를 변경하지 않는다. DB 상태 갱신은 기존 인증상태 처리 업무에서 수행하며 이 화면은 읽기 전용이다.
- 후보자 전체 목록·연결 신청·보관 상태를 다시 조회할 수 있다. 실패 시 수량·상태가 미확인임을 안내하고 이전 응답을 반영하지 않는다.
- 보관 상태 조회 실패 중에는 일반/보관 분류를 적용하지 않고 전체로 표시한다고 안내한다. 일반·보관 구분을 확정하지 않는다.
- 추가 SQL이나 개인정보 권한 변경은 없다. 기본 샘플은 등록 후보자와 별도 집계한다. 네트워크 장애·권한별 화면 검증은 별도로 필요하다.
