# 인증분야 확장

설정 → 기준정보 → 인증분야·표준 추가에서 ISO 및 K뷰티 분야를 등록한다.
사업 분야, 인정기구(IAS/PJLA), 인정 구분, 분야명, Job 접두어, 인증번호 분야 코드를 입력한다.
인정 선택은 기관의 실제 인정범위를 확인한 경우에만 사용한다. 등록 자체가 인정 취득을 의미하지 않는다.

공유 환경에서는 기존 system_settings 테이블의 certification_fields_v1 키로 저장한다.
별도 SQL은 추가하지 않는다. 기존 테이블의 관리자 쓰기 권한과 실무자 읽기 권한을 사용한다.
로컬 시제품에서는 해당 브라우저에만 저장되므로 다른 기기에 공유되지 않는다.

등록 후 새 신청 화면에서 해당 분야를 선택할 수 있고 Job·인증번호 부여에 같은 규칙을 사용한다.
지정 연수기관 관리에서도 등록된 분야를 검색해 신청표준 입력에 추가할 수 있다.
기존 자유 입력은 유지하며, 분야 선택만으로 지정범위나 인정상태를 승인하지 않는다.
번호 부여 응답은 설정 접두어와 네 자리 순번이 정확히 일치해야 업무 입력에 적용한다.
잘못된 응답은 저장하지 않는다. 이미 예약됐을 가능성이 있으므로 DB 예약 상태를 확인하고 번호를 재사용하지 않는다.
Job 및 기존 ISO 인증번호의 로컬 예상 순번은 9999 소진 시 생성하지 않는다.
설정 조회 오류 시 번호 부여와 인증정보 확정을 중단한다. 추가 실패 시 다시 조회한 뒤 실제 저장 여부를 확인한다.
동시 설정 변경은 기존 수정 시각 조건으로 충돌을 검출한다. 기존 규칙 및 이력을 수정하거나 삭제하지 않는다.

Job 접두어와 같은 인정기구·사업 분야의 인증번호 코드는 중복할 수 없다.
ISO/IAS는 기존 8자리 형식을 유지하므로 분야 코드가 숫자 한 자리이다. 코드 소진 시 번호체계 확장은 별도 결정한다.
등급 체계 및 분야별 제출서류·교육·심의 요건은 이 기능으로 자동 추가되지 않는다.

자동검사는 순수 규칙, 중복, 신규 신청·번호 생성 연결, 설정 저장 성공·실패·충돌을 검증한다.
실제 운영 DB의 권한 및 새 분야의 업무요건은 운영 전 별도 확인이 필요하다.
