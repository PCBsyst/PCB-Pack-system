# 신청 목록 조회 정합성

## 2026-10-04 개선

- 공유 연결기록 조회 훅으로 신청·Job·업무기록을 조회하고 재조회 버튼을 제공한다. 로딩과 조회 실패를 실제 빈 목록과 구분한다.
- 여러 Job을 가진 신청은 신청 ID로 묶어서 한 행에 모두 표시한다. 관리 No.도 각 Job의 번호를 표시한다.
- 표준·등급 필터와 검색은 신청의 모든 Job을 대상으로 적용한다. 표준과 등급은 각각 일치 여부를 검사하므로 서로 다른 Job에서 조건을 만족할 수 있다.
- 등록 신청에 접수일·후보자·파트너사·표준·상태 정렬을 적용한다. 기본 샘플과 등록 신청은 별도 구간이며 두 구간을 합친 전역 정렬은 아니다.
- 등록 신청 수와 기본 샘플 수를 구분한다. 조회 실패 시 표시 수량이 확정값이 아님을 안내한다.
- 연결 후보자는 실제 후보자 ID가 있으면 해당 상세로 연결한다. Job 미부여 신청은 기존 공유 조회 훅의 표시 범위 밖이며 별도 접수 대기 처리 개선이 필요하다.
- 개인정보 조회·RLS 정책은 이번 작업에서 변경하지 않았다. 추가 SQL은 없으며 실제 사용자 화면 검증은 별도다.
