## 보완

검토 의견, 교육·시험 요약, 심의위원 의견과 대표자 승인 의견, 전달 기록 등의 여러 줄 값이 Word 텍스트 안의 개행 문자로만 삽입되던 문제를 수정했습니다. CRLF·CR·LF를 실제 `w:br` 요소로 출력하며 XML 특수문자는 먼저 이스케이프합니다. 서류검토서·인증결정보고서·문서전달확인서 및 국문 전달확인서 초안에 적용했습니다.

검사: `scripts/test-document-routes-output.mjs` — 세 경로의 국영문 생성, 후보자·Job·시험 및 날짜 값, 검토 의견과 선택 위원 및 대표자 승인 의견, 필수 입력 칸 누락 거절, 파일 오류·권한·저장값·이력 오류 시 미다운로드, 실제 줄바꿈 XML 및 특수문자 보호. 출력 페이지를 직접 본 검사가 아닙니다.

## 양식 상태

내장 정식 국문 서류검토서와 인증결정보고서는 있습니다. 국문 문서전달확인서는 정식 미등록이며 기존 검토용 초안은 정식 패키지 완료에 포함되지 않습니다. 영문 서류검토서·인증결정보고서도 내장 정식 미등록입니다. 운영에 따로 등록한 양식의 존재는 이번 검사에서 확인하지 않았습니다.

## 시각 검증 대기

제공된 런타임에 문서 스킬이 요구하는 번들 LibreOffice 변환기가 없어 페이지 PNG 렌더링과 잘림·페이지 배치·워터마크·머릿글/바닥글의 시각 검증을 수행하지 못했습니다. 사용자의 데스크톱 변환기로 임의 대체하지 않았습니다. 바이너리 양식의 디자인이나 정식 등록 상태도 변경하지 않았습니다.

향후 정상 렌더링 환경에서 짧은 의견·여러 줄 긴 의견·교육 정보·긴 기관명·한글 특수문자 등의 페이지를 모두 확인하고 조정해야 합니다. 이번 점검을 공식 PDF·국문 패키지 전체 완성으로 표시하지 않습니다.

## 긴 의견 및 본문 승인 의견 추가 검사

40줄 의견의 각 줄과 특수문자가 빠지지 않는지, 긴 입력 전후 기업 머릿글·바닥글·이미지 파일이 바뀌지 않는지 검사했습니다. 전달확인서는 항목별 비고 칸을 추가한 시험 양식에서 긴 의견을 검사했으며 기존 내장 영문 양식에 비고 칸이 있다고 주장하지 않습니다.

대표자 승인 의견의 전용 칸 판단을 본문의 실제 텍스트 요소로 제한했습니다. 머릿글이나 XML 주석에만 입력 키가 있으면 본문 심의 의견 영역에 대표자 승인 의견을 따로 출력합니다. 본문에 전용 칸이 있으면 중복 출력하지 않습니다. 페이지 시각 검증 대기 상태는 그대로입니다.
