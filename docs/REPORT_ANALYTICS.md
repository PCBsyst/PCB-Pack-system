# 고객 및 수익 분석

월간 업무보고의 분야·등급·신청 유형별 집계와 선택 연도 월별/최근 5년 연별 고객 추이를 제공한다. 표준·파트너 필터를 함께 적용한다. 후보자 ID별 고객 중복을 제거하지만 여러 분야나 상태에 속한 고객은 각 그룹에 포함되므로 행 합산값은 전체 고유 고객 수와 다를 수 있다.

청구액은 인보이스 발행일, 실제 입금액은 paid_at/paid_amount 기준이다. 현재 DB에 통합 인보이스의 Job별 상세 금액이 없으므로 전체 연결 Job 수로 균등 배분한다. 필터를 적용해도 분모를 줄이지 않는다. KRW 운영 기준의 참고 분석이며 회계상 매출 확정이나 세금 계산을 대체하지 않는다. 수익 조회 실패/미연결은 미확인으로 표시한다.

고객 추이는 접수 시기별 고객의 현재 상태 분포이다. 과거 월말/연말 유지 고객의 실제 상태 복원은 아직 제공하지 않는다. 정지/철회/복구/갱신 대체의 전체 이벤트 모델을 확보하고 검증한 후 구현해야 한다. 일반 인증 만료를 자동 정지 처리하지 않는다.

분석 결과는 별도 CSV로 내려받는다. 문서/CSV는 다크 UI와 무관하게 기존 출력 형식을 유지한다. 신규 SQL 불필요. 실 DB 데이터와 인보이스 연결 누락·부분 입금·상태이력의 운영 검증은 별도 필요하다.
