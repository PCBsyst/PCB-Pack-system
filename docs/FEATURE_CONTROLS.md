# 부가 기능 ON/OFF — 1차 범위

## 구현

- 설정 → 보안·이력의 부가 기능 제어 카드.
- 서버 문서 생성, 서버 패키지 ZIP 다운로드 두 기능만 대상.
- 최고관리자만 필수 사유와 확인 후 변경. DB 함수에서 권한·동시 변경 검사.
- 설정 변경은 기존 감사 트리거로 실행자, 전후 값, 시각, 사유 보존.
- 인증검사 완료 후 각 문서 API에서 매 요청 설정 조회. 권한/네트워크 오류, 설정 행 누락은 503으로 차단. OFF는 403으로 차단.
- ZIP은 문서 생성과 ZIP 다운로드 모두 ON이어야 생성 가능.
- 로그인, 권한, 연결된 접근/변경 추적, 필수 사유, 이력 보호를 해제하는 설정은 제공하지 않음.

## 적용 전 호환성

SQL 021은 아직 적용하지 않았다. 새 feature_controls 테이블이 없다는 명확한 DB 오류(42P01/PGRST205 및 해당 테이블명)만 기존 문서 생성 동작을 유지한다. 일반 권한 오류 등은 우회하지 않는다. UI는 설정을 불러오기 전까지 변경 버튼을 비활성화한다.

## 범위 밖

브라우저 직접 생성 문서, 내부 알림, 자료 이관, Dropbox 연동은 아직 제어하지 않는다. 보안 핵심 설정을 단순 표시만으로 구현 완료로 간주하지 않는다. 이미 시작한 응답/사용자가 보유한 다운로드 파일은 OFF로 회수하지 않는다. 신규 요청은 최신 설정을 확인한다.
