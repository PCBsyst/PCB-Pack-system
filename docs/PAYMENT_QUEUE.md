# 대시보드 입금 대기

대시보드에 인보이스 단위 입금 대기 목록을 추가한다. 통합 인보이스는 한 번만 집계하며 실제 invoices의 amount/paid_amount/payment_status/paid_at을 사용한다. 잔액은 청구액에서 입력된 입금액을 빼고 0 이하로 내리지 않는다.

부분 입금, CHECK_REQUIRED, PAID와 잔액/입금일 불일치를 확인 필요로 표시한다. 납기일이 없으므로 연체라고 판단하지 않는다. 검색/확인 필요 필터/10건 페이지 이동/새로고침/연결 Job 링크를 제공한다. 화면에서 직접 입금 상태를 변경하지 않는다.

전체 인보이스를 500건씩 조회하고 실패하면 0건으로 표시하지 않는다. 신규 SQL은 불필요하다. 관련 입력 정확성 및 실 DB 권한별 동작 검증은 별도이다.
