# 인증 만료일 확인

대시보드에서 history_state=CURRENT, state=ACTIVE/SUSPENDED, issue_date가 한국 기준 조회일 이전/당일인 인증을 조회한다. 철회 및 갱신 대체 이력은 제외한다. 30/60/90일 이내(오늘 포함)와 만료일 경과를 구분하고 이름/인증번호/표준 검색 및 Job 링크를 제공한다.

만료일 차이는 달력일 기준이다. 한국 날짜를 사용하며 UTC 날짜 계산으로 기기 시간대 및 DST 영향을 피한다. 유효기간과 인증상태는 읽기만 하며 경과일을 이유로 자동 정지/철회하지 않는다. 만료 당일과 만료 후를 구분한다. 조회일은 새로고침 때 갱신된다.

조회 실패는 0건이 아닌 미확인 안내를 제공한다. 500건 단위 조회 및 10건 화면 페이지 이동을 사용한다. 신규 SQL 불필요. 실제 DB 관계/역할별 조회 검증은 별도 필요하며 자동 알림·이메일·자동 갱신 신청 기능은 포함하지 않는다.
