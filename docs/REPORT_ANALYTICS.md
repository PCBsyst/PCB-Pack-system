# 고객 및 수익 분석

## 현재 제공 기능

보고서 상단 공통 조회 조건에 등급·신청유형을 추가했다. 월간 상세/인쇄/CSV와 고객·수익·현재 상태·실제 상태변동 분석이 동일한 분야·표준·파트너·등급·유형 조건을 사용한다. 날짜는 각 지표의 접수일/발행일/입금일/상태 적용일 기준을 유지한다.

추가: certification_actions의 effective_date를 기준으로 실제 정지·철회 월/연 변동을 별도 표시한다. 고유 고객 수와 처리 건수를 구분하며 같은 이벤트 ID는 중복 제거한다. 조회 실패는 0건으로 표시하지 않는다. 미래 적용일도 그 기간에 포함하므로 완료 실적과 동일하지 않다. 기존 010 상태변동 테이블을 사용하며 신규 SQL은 없다. 복구/갱신 대체 전체 이력이나 과거 월말 유지 고객 수 복원은 여전히 미구현이다.

월간 업무보고의 분야·등급·신청 유형별 집계와 선택 연도 월별/최근 5년 연별 고객 추이를 제공한다. 표준·파트너 필터를 함께 적용한다. 후보자 ID별 고객 중복을 제거하지만 여러 분야나 상태에 속한 고객은 각 그룹에 포함되므로 행 합산값은 전체 고유 고객 수와 다를 수 있다.

청구액은 인보이스 발행일, 실제 입금액은 paid_at/paid_amount 기준이다. 현재 DB에 통합 인보이스의 Job별 상세 금액이 없으므로 전체 연결 Job 수로 균등 배분한다. 필터를 적용해도 분모를 줄이지 않는다. KRW 운영 기준의 참고 분석이며 회계상 매출 확정이나 세금 계산을 대체하지 않는다. 수익 조회 실패/미연결은 미확인으로 표시한다.

고객 추이는 접수 시기별 고객의 현재 상태 분포이다. 과거 월말/연말 유지 고객의 실제 상태 복원은 아직 제공하지 않는다. 정지/철회/복구/갱신 대체의 전체 이벤트 모델을 확보하고 검증한 후 구현해야 한다. 일반 인증 만료를 자동 정지 처리하지 않는다.

분석 결과는 별도 CSV로 내려받는다. 문서/CSV는 다크 UI와 무관하게 기존 출력 형식을 유지한다. 신규 SQL 불필요. 실 DB 데이터와 인보이스 연결 누락·부분 입금·상태이력의 운영 검증은 별도 필요하다.

## 전년 비교와 AI 마케팅 분석 개발 범위

### 자료 준비 상태와 월별 관측 비교

2026-11-20 월간 업무보고에 신규 고객 비교와 자료 준비 상태 구역을 연결했다. 서버 API `/api/reports/customer-acquisition`가 신청과 Job을 각각 분할 재조회하고 관계·건수·날짜를 확인한다. 후보자 이름·생년월일·연락처는 조회하지 않으며 브라우저에는 고객 ID나 행 단위 이력 없이 집계만 반환한다. 기존 상세 보고서의 신청별 문서 응답 이력과는 별개인 내부 집계 조회다. 외부 AI 호출은 없다.

Job 없는 첫 신청도 전체 관측 고객 수에 포함한다. 전체 이력에서 후보자별 최초일과 후보자·분야·표준 조합의 최초일을 먼저 구하고 분야·표준·파트너 필터를 적용한다. 같은 날 여러 표준을 처음 신청한 경우는 기존 고객의 후속 추가로 세지 않는다. 취소 접수는 제외하며 미래 접수는 실적에 포함하지 않는다. 전체 신청/Job 수, Job 없는 신청, 취소·미래 접수, 유효 접수 관측 범위를 표시한다.

비교는 접수 기준이다. 상단 월은 비교 연도 선택에 사용하고 등급·유형·현재 상태·인증발행일 필터는 적용하지 않는다고 표시한다. 진행 월은 전년도 같은 날짜까지 비교하고 윤년은 유효한 마지막 날짜로 맞춘다. 미래 월은 미도래로 둔다. 과거 이력이 완전하다는 승인 근거가 아직 없으므로 실제 신규 고객 수·신규 증감률·유지율·갱신율은 항상 산출 보류이며 관측 첫접수 숫자를 이 지표로 대체하지 않는다. 브라우저 요청으로 이력 확인 상태를 변경할 수 없다.

월별 막대 비교와 집계 CSV를 제공한다. CSV에도 관측 기준, 비교 종료일, 산출 보류를 유지한다. 개발용 가상 예제는 별도로 선택하며 DB와 섞거나 저장하지 않는다. 실패·부분 조회·손상 응답은 0건으로 표시하지 않고, 조건 변경 시 이전 결과와 늦게 도착한 응답을 폐기한다. 개별 페이지 조회 검증은 트랜잭션 시점의 완전한 스냅샷 보장을 뜻하지 않는다. API는 직원 권한·세션·MFA 검사를 적용하고 캐시를 금지한다. 신규 SQL은 필요하지 않다.

### 후속 비교 지표와 AI 요약

2026-11-20 [AI 경영 및 마케팅 분석 설계](AI_MARKETING_ANALYTICS_DESIGN.md)를 추가했다. 전년 대비 월별 신규 고객 증감, 기초 고객 집단 유지율, 갱신율, 당시 등급·표준별 추세 및 근거를 연결한 국문 AI 요약을 개발한다.

기존 접수 기간별 고객의 현재 상태 표를 과거 유지율로 바꾸어 부르지 않는다. 최초 접수 이력 범위, 정지·복구·철회 및 대체 인증의 과거 연결을 먼저 진단한다. 자료 부족은 산출 불가로 표시하고 전년 0명, 진행 월 및 잠정 갱신 대상도 별도로 처리한다.

AI 입력은 개인정보 보호 기준을 통과한 집계값으로 제한한다. 제공업체 설정과 전송은 아직 활성화하지 않는다. 추가 SQL·이관 이력 보강 필요 여부는 집계 기반 구현 단계에서 확정하며, 기존 기능에 대한 신규 SQL 불필요 안내를 이 확장 범위에 적용하지 않는다.
